# Compliance

## Datree

- Official: <https://www.datree.io/>
- GitHub: <https://github.com/datreeio/datree>

Policy enforcement engine with 100+ built-in rules covering security, HA, NSA hardening, and Argo CD best practices. Note: project is no longer actively maintained.

## Kube-linter

- Official: <https://docs.kubelinter.io/>
- GitHub: <https://github.com/stackrox/kube-linter>

StackRox/Red Hat static analysis tool that checks Kubernetes YAML and Helm charts for production-readiness and security best practices.

## Kubeconform

- GitHub: <https://github.com/yannh/kubeconform>
- Schemas GitHub: <https://github.com/yannh/kubernetes-json-schema>

Fast, configurable Kubernetes manifest validator that uses JSON schemas to validate resources against the cluster's API. Drop-in replacement for kubeval.

## Kubeval

- GitHub: <https://github.com/instrumenta/kubeval>

Original Kubernetes manifest schema validator (now mostly superseded by kubeconform).

## Kube-score

- Official: <https://kube-score.com/>
- GitHub: <https://github.com/zegl/kube-score>

Static analysis of Kubernetes object definitions, recommending security and reliability improvements.

## Kubescape

- Official: <https://kubescape.io/>
- GitHub: <https://github.com/kubescape/kubescape>

CNCF Incubating Kubernetes security platform that scans clusters, manifests, and Helm charts against frameworks like NSA-CISA and MITRE ATT&CK.
